This project is a simple port scanner developed in Python using the built-in socket library. The program allows the user to input a target IP address and systematically scans all ports in the range of 1 to 65535.

For each port, the script attempts to establish a connection and determines whether the port is open or closed. The results are printed in real time, making it useful for educational purposes, basic network analysis, and understanding how port scanning works.

Features:

Scans all TCP ports (1–65535)
User-defined target IP address
Real-time output of port status
Built with Python’s standard socket library
